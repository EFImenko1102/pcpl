# Рубежный контроль №1

## 1. Постановка задачи

Разработать программу на языке Python, моделирующую предметную область **«Колонка данных — Таблица данных»**:
1. Создать два класса данных:
   - **`Column` («Колонка данных»)** — сторона «много» в отношении один-ко-многим:
     - `id`: уникальный идентификатор записи о колонке данных;
     - `name`: наименование колонки (строка);
     - `size`: количественный признак — размер данных в байтах (целое число);
     - `table_id`: внешний ключ — ID таблицы для связи 1:M.
   - **`Table` («Таблица данных»)** — сторона «один» в отношении один-ко-многим:
     - `id`: уникальный идентификатор записи о таблице данных;
     - `name`: наименование таблицы (строка).
   - **`TableColumn` («Колонки таблицы данных»)** — класс для реализации отношения многие-ко-многим:
     - `table_id`: ID таблицы данных;
     - `column_id`: ID колонки данных.
2. Создать списки объектов классов с тестовыми согласованными данными.
3. Реализовать запросы **Варианта Б** с использованием функциональных возможностей Python (`list comprehensions`, `filter`, `sorted`, `lambda`, `itemgetter`):
   - **Запрос Б1 (1:M):** Вывести список всех связанных колонок данных и таблиц данных, отсортированный по колонкам данных (по наименованию колонки), сортировка по таблицам данных произвольная.
   - **Запрос Б2 (1:M):** Вывести список таблиц данных с количеством колонок данных в каждой таблице, отсортированный по количеству колонок данных (по убыванию).
   - **Запрос Б3 (M:N):** Вывести список всех колонок данных, у которых наименование заканчивается на «ов», и названия их таблиц данных.
4. Оформить отчет по форме лабораторных работ кафедры ИУ5.

